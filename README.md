## Depannage

| Symptome | Cause | Solution |
|---|---|---|
| `OpenProcess a echoue (code 5)` | process non eleve | accepte l'UAC ; si tu l'as refusee, relance en clic droit > Executer en tant qu'administrateur |
| `code 5` malgre l'admin | un overlay tient le handle | ferme Overwolf / MSI Afterburner / RivaTuner, injecte dans le lobby |
| `le process a disparu (code 87)` | jeu ferme pendant l'injection | relancer Fortnite puis l'exe |
| rien ne s'affiche en jeu | rendu DirectX 12 | passer en DirectX 11 dans les options |
| pas de menu | injection trop tot | injecter une fois dans le lobby |
